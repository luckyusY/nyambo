# Inkindi decor Kigali

A Next.js App Router website for Inkindi decor Kigali, a Rwanda-based event design and production company. The site uses the provided event imagery and video assets to create a refined, editorial landing page with a hero film, services, gallery, testimonials, and contact section.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Project structure

- `src/app/page.tsx` contains the landing page experience.
- `src/app/globals.css` contains the responsive visual system.
- `public/assets/images` and `public/assets/videos` contain Inkindi decor Kigali event media.
